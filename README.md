# WebAI

WebAI is a browser-based AI workspace powered by the Groq API.

## Run locally

1. Download and extract `WebAI-source.zip`.
2. Open a terminal in the extracted `billai` folder.
3. Run `npm install` and then `npm run dev`.
4. Open Settings in WebAI and enter your own Groq API key.

The API key is stored in your browser's local storage. Never commit or share your key.

## GitHub Pages

The repository includes a GitHub Actions workflow to build and deploy the app. In **Settings → Pages**, select **GitHub Actions** as the build and deployment source.
